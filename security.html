Security and trust

Built to be understandable before it is trusted.

QuitBuddy is a direct-download macOS utility. This page summarizes what it asks for, what stays local, and how to report security concerns.

Local Settings stay on your Mac

Per-app rules and preferences are stored locally and can be exported only when you choose.

Signed Developer ID distribution

Direct builds are signed, notarized, and distributed as a macOS DMG.

Minimal No app telemetry SDKs

The app does not include advertising, analytics, crash-reporting, keystroke-history, or click-history collection.

Permissions

Input Monitoring is used to detect Command-Q for configured quit protection and optional red close-button quit clicks. Accessibility is used to return focus and send a confirmed quit action after you explicitly choose to quit.

Data handling

QuitBuddy does not record typed content, upload keyboard input, sell data, or build usage profiles. Settings and diagnostics remain local unless you explicitly export or share them.

Licensing

Lemon Squeezy handles checkout, payment processing, license delivery, and license validation. QuitBuddy stores license state in the macOS Keychain and does not receive credit card details.

Updates

Direct-download builds use Sparkle for signed updates. Update checks use public metadata from getquitbuddy.com and do not include your protected apps, settings, license key, or quit history.

Security contact

Report suspected vulnerabilities to quitbuddy.support@gmail.com. Include reproduction steps, impact, macOS version, QuitBuddy version, and any relevant logs with secrets removed.
