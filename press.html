How QuitBuddy works in one paragraph

QuitBuddy installs as a small macOS menu-bar app. After granting Input Monitoring and Accessibility (the same permissions every text-expansion or keyboard tool needs), you tell QuitBuddy which apps matter and how each one should respond when you press Command-Q. The default is Confirm — QuitBuddy briefly asks before the app quits. Other options include Hold (press-and-hold Command-Q to commit), Double-press (press Command-Q twice), Allow Normal Cmd-Q (no guard — let the app quit normally), and Never Quit (block Command-Q entirely for an app you don't want closing by accident). Standard also includes a global mouse workflow setting that makes a standard Mac window's red close button quit the whole app like ⌘Q. Free protects one app; Standard unlocks unlimited per-app rules.

What QuitBuddy is not

  • Not a keylogger. Input Monitoring is used only to detect configured quit actions: Command-Q and optional close-button quit clicks.
  • Not a keyboard remapper. System Command-Q still works exactly as macOS defines it — QuitBuddy only changes the apps you ask it to change.
  • Not a Karabiner-like configuration tool. No scripts, no per-app config files, no Hammerspoon-style code.
  • Not a subscription. Standard is a one-time purchase you own forever.
  • Not on the Mac App Store. The per-app keyboard-shortcut model isn't compatible with App Review; direct download is the only public channel.
  • Not an accessibility-medical product. It can help users with motor-precision sensitivity, but it makes no medical claims.
